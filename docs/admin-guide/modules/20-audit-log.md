# Audit log

Who can use it: everyone (Super Admin sees everyone's changes; others see their own)

Every change in the admin is recorded: who, what, when, and the value before and after. Entries can't be edited or deleted. Passwords, codes and full PANs are never written here.

![Audit log](img/audit-log.jpg)

## Finding something

Filter by **Person**, **Record type** (donation, receipt, cause, page…) and dates **From (IST)** / **To (IST)**. Open an entry to see exactly what changed.

## When to use it

- "Who changed this page?" or "When was this receipt reissued, and why?"
- A monthly check by a trustee that nothing unexpected happened.
- Answering an auditor's questions about corrections.
