# Menus

Who can use it: Super Admin and Content Editor

Order, rename and hide the links in the header and footer, or add links to causes, news, events and other sites.

![Menus](img/menus.jpg)

## The four menus

- **Header:** the main menu at the top of every page. Header links can open a dropdown of sub-links.
- **Footer: Explore:** the first link list in the footer.
- **Footer: The Trust:** the second list.
- **Footer: Legal:** the small links at the very bottom.

## Changing a menu

1. Drag links (or use the arrows) to change the order.
2. Rename a link, hide it, or add a new one: a site page, a cause, a news post, an event, or another website.
3. **Save menu**, then check the site in each language.

Pages that aren't live yet and drafts never show in menus.

**Reset this menu** brings back the built-in menu and removes your changes.
