# Causes

Who can use it: Super Admin and Content Editor (Accountant: read only)

Causes are what donors can give towards, for example school support. Each cause has its own page, its card on the causes list and Home, and can be chosen on the donate form.

![Causes list](img/causes-list.jpg)

## Adding a cause

1. **Causes → New cause.** Fill in the settings first; you write the text in each language next.
2. **Web address:** lowercase words with hyphens, e.g. `school-support`. It becomes /en/causes/school-support. Changing it later breaks links people already shared.
3. **Status:** Draft, Active (taking donations) or Closed.
4. **Goal (₹):** optional. The amount raised is counted from donations automatically.
5. **Order:** lower numbers are listed first.
6. **Cover photo**, **Card icon**, **Card label** and an optional **Photo slider** shown below the story.
7. **80G eligible:** whether donations to this cause qualify for 80G receipts.
8. Save, then write the **Title**, **Summary** (for cards) and **Text** in each language, and tick reviewed.

![Editing a cause](img/causes-edit.jpg)

## Things to remember

- A cause appears in a language only once that language's text is reviewed.
- Only drafts that never received a donation can be deleted. Close a cause instead of deleting it.
