# Events

Who can use it: Super Admin and Content Editor

Events are the Trust's upcoming and past programmes: camps, distributions, annual days. Upcoming events are listed first; past ones move down automatically.

![Events list](img/events-list.jpg)

## Adding an event

1. **Events → New event.** Fill in the settings: web address, status, **Starts (IST)** and **Ends (IST)**, the venue (name and address) or an **Online link**, and a cover photo.
2. Save, then write the title, summary and description in each language.
3. Tick **Reviewed by a person: publish in this language** and save.

![Editing an event](img/events-edit.jpg)

Events also appear to search engines with their date and place, so keep times and venues correct. If an event is cancelled or moved, update it rather than deleting it.
