# Sample content

Who can use it: Super Admin

Example causes, events, news, a gallery album and documents with sample photos, so every page can be tried and edited. Use it on **stage** for training, not on the live site.

![Sample content](img/sample.jpg)

- **Load sample content:** downloads 20 free sample photos and creates the sample items as unreviewed drafts. Items whose web address already exists are skipped, so it is safe to run again. Takes up to a minute.
- **Remove sample content:** deletes sample items nobody has approved (and causes without donations), then the sample photos no longer used anywhere. Items someone has reviewed are kept.
- **In the database now** shows how many sample items are still there.
