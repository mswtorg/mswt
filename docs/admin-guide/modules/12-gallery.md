# Gallery

Who can use it: Super Admin and Content Editor

Photo albums, for example "Annual day 2026". An album appears in a language once its title in that language is reviewed.

![Gallery albums](img/gallery-list.jpg)

## Making an album

1. **Gallery → New album.** Choose the web address (e.g. `annual-day-2026`), status, date (optional), order and the **Album photos** from the library. The cover is the first photo unless you choose one.
2. **Create album**, then add the title and description in each language and tick reviewed.

![Editing an album](img/gallery-edit.jpg)

Deleting an album does not delete its photos; they stay in Media.

Every photo needs alt text in each language the album is shown in. Add it in **Media**.
